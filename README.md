# Bunny's Gospel Game

A tap-to-play game for little ones (about age 5) from **StayTheWay Kids**, based on Galatians 2: we can't earn God's love. Jesus loved me and gave Himself for me, and Jesus lives in me!

**Play:** https://weiszdev.github.io/bunny-gospel-game/

It's a single self-contained `index.html` that works offline once loaded. For parents: https://staytheway.com
